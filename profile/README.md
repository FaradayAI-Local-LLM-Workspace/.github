## What is Faraday AI?

Faraday AI (rebranded as Backyard AI) operates as a zero-configuration desktop environment and offline inference workstation designed for local character chat, AI storytelling, and interactive roleplay. Built to make local artificial intelligence accessible to non-technical users, Faraday AI eliminates manual terminal commands and complex backend setups by auto-detecting client hardware to configure GGUF model parameters, VRAM allocation, and thread counts out of the box.

Integrating Faraday AI into local creative writing and character development workflows unifies model execution, persona customization, and long-term memory management. The application features a integrated Character Hub that allows users to discover, import, and configure custom AI personas with specialized system prompts, greeting templates, and lorebook world definitions. All conversation histories, prompt iterations, and character datasets are stored locally on the client machine to guarantee total data privacy.

As a modern desktop execution engine, Faraday AI supports open-weights models such as Llama, Mistral, Qwen, and Gemma. Built-in layer offloading dynamically distributes model weights between GPU VRAM and system CPU RAM, enabling low-latency text generation on consumer hardware alongside optional mobile tethering for remote local chat sessions.
